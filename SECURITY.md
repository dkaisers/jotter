# Security

jotter stores all data in the browser's localStorage — nothing is sent to a
server. If you still find a security issue, please report it privately rather
than opening a public issue.

## Reporting a vulnerability

- Email: dominik@dkaisers.net
- Please include the affected version/commit, a description of the issue, and
  steps to reproduce if possible.

You will receive a response acknowledging the report. Please allow reasonable
time for it to be assessed before disclosing it publicly.
